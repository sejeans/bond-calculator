# Bond Lab — 파이썬 채권 계산기

고정금리 이표채의 이자·원금을 날짜별로 만들고, 할인한 현금흐름에서 가격과 금리 위험을 계산합니다. 금융 계산 라이브러리 없이 파이썬 표준 라이브러리로 구현했습니다.

## 바로 실행

이 폴더의 **`실행.cmd`를 더블클릭**합니다. 파이썬 3.10 이상과 Tkinter가 필요하며, 현재 컴퓨터의 Python 3.14.3 / Tk 8.6에서 실행을 확인했습니다. 추가 패키지는 설치하지 않습니다.

터미널에서 이 프로젝트 폴더를 열었을 때:

```powershell
python -m bondcalc --gui
python -m bondcalc --output reports/ktb-example.json
python -m bondcalc.disclosures
python -m unittest discover -s tests -v
```

계산기 화면에는 네 탭이 있습니다.

| 탭 | 할 수 있는 일 |
|---|---|
| 가격과 민감도 | Dirty/Clean 가격, YTM, Macaulay/Modified 듀레이션, 컨벡시티, DV01, ±100bp 가격 시나리오와 근사 오차 |
| 현금흐름 | 이표 지급일, 이자, 원금, 할인계수, 현재가치, 현재가치 비중 확인 |
| 키레이트 듀레이션 | 만기별 제로금리 편집, 개별 노드 ±1bp 재평가, KRD 합과 평행이동 민감도 비교 |
| 시장가격 비교 | 관측가격에서 YTM 역산 또는 독립적으로 관측한 가격·YTM의 괴리 계산 |

입력값을 바꾸면 기존 결과를 비우고 저장 버튼을 잠급니다. 다시 계산한 결과만 저장됩니다. `입력·결과 JSON 저장`에는 입력값과 현금흐름, 시나리오, KRD, 시장가격 비교가 함께 들어갑니다. 저장한 파일을 다시 열어 재현할 수 있습니다.

## 입력 단위

- **화면**의 금리는 `%`: 3%이면 `3`을 입력합니다.
- **JSON·파이썬 함수**의 금리는 소수: 3%이면 `0.03`입니다.
- 1bp는 0.01%p, 소수로는 0.0001입니다. +100bp는 금리 +1%p입니다.
- 가격은 입력한 액면금액 기준의 원화 금액입니다. 기본 액면금액은 10,000원입니다.
- DV01은 금리가 1bp 상승할 때의 가격 하락액을 1차 근사한 양수입니다. 실제 상승 충격의 가격 변화 부호는 음수입니다.
- `결제일`은 채권을 인수하는 기준일입니다. 자동으로 오늘 날짜나 거래일 다음날로 변환하지 않습니다.

## 계산 원리

액면금액 `F`, 연 표면금리 `c`, 연 이자 지급 횟수 `m`, 연 명목 YTM `y`를 사용합니다. 정기 이자 `C=F*c/m`이며 마지막 지급일에는 원금 `F`를 더합니다.

`f`는 다음 이자 지급일까지 남은 실제 일수 / 현재 이자기간의 실제 일수입니다. 첫 미래 현금흐름부터 `k=0,1,...`로 번호를 매기고 `t=(k+f)/m`년을 사용합니다. 정규 기간에 대한 Actual/Actual 이표기간 분할 방식이며 Actual/365와는 다릅니다.

### 교과서 복리 (`compound`)

```text
q = 1 + y/m
PV_k = CF_k / q^(k+f)
Dirty = sum(PV_k)
Macaulay = sum(t_k * PV_k) / Dirty
Modified = Macaulay / q = -P'(y)/P(y)
Convexity = sum[PV_k * t_k * (t_k + 1/m) / q^2] / Dirty
```

### 국고채 단리 (`ktb_simple`)

다음 이표일까지는 단리, 그 뒤 온전한 이표기간은 복리로 할인합니다. 한국은행 발행공고의 일반 매출 산식을 구현했습니다.

```text
s = 1 + (y/m)*f
PV_k = CF_k / [q^k * s]
a_k = k/(m*q) + f/(m*s)
b_k = k/(m*q)^2 + [f/(m*s)]^2
Modified = sum(PV_k * a_k) / Dirty
Convexity = sum[PV_k * (a_k^2 + b_k)] / Dirty
```

두 방식 모두 Macaulay는 현금흐름의 현재가치 가중 평균 회수기간으로 표시합니다. **단리 모드의 Modified는 정확한 가격 1차 미분에서 계산하므로 `Macaulay/(1+y/m)`와 일반적으로 다릅니다.** 이표일에는 `f=1`이어서 두 방식이 일치합니다.

```text
경과이자 = C * (결제일−직전 이표일 실제 일수) / (현재 이표기간 실제 일수)
Clean = Dirty − 경과이자
DV01 = Modified * Dirty * 0.0001
가격 변화 1차 근사 = −Modified * Dirty * Δy
가격 변화 2차 근사 = 1차 근사 + 0.5 * Convexity * Dirty * (Δy)^2
```

컨벡시티 출력값에는 `1/2`을 포함하지 않습니다. 2차 근사식에서 곱합니다. 민감도 분모는 Dirty 가격입니다. 결제일을 고정한 금리 충격에서 경과이자는 일정하므로 Clean과 Dirty의 **금액 변화**는 같고 **비율 변화**는 다릅니다.

YTM은 목표가격과 계산가격의 차이가 0이 되는 금리를 이분법으로 찾습니다. 음수 금리도 허용하고 상한을 자동으로 확장합니다. Clean 입력이면 경과이자를 더한 후 계산합니다. 가격을 단조 감소시키는 정규 비음수 현금흐름의 이표채를 대상으로 합니다.

### 키레이트 듀레이션

제로금리란 해당 만기에 한 번 지급되는 현금흐름의 할인금리입니다. 국고채 대표물 YTM은 여러 이표 현금흐름을 합친 채권의 수익률이므로 그 자체로 제로금리가 아닙니다. 실제 제로커브 생성에 필요한 부트스트래핑은 이번 범위에 포함하지 않습니다.

- 만기별 연 명목 제로금리를 입력하며 채권의 이자 지급 횟수와 같은 복리 기준을 사용합니다.
- 현금흐름 기간 `t=(k+f)/m`에 맞춰 선형 보간합니다. 양 끝 바깥에서는 가장 가까운 노드 금리를 유지합니다.
- 노드 하나를 ±1bp 움직이고 보간을 다시 하여 전체 채권을 재평가합니다.
- `KRD_i = [P(z_i−h)−P(z_i+h)] / (2*h*P(z))`이며 기본 `h=0.0001`입니다.
- 모든 노드를 함께 움직인 평행이동 민감도와 개별 KRD의 합을 비교합니다. 유한 충격의 고차항 때문에 아주 작은 차이가 남습니다.
- 평탄 커브에서는 **복리 YTM** 가격·Modified와 일치합니다. 단리 YTM 모드에서는 별도 커브 가격을 표시합니다.
- 커브는 학습용 입력이며 실제 시장 제로커브를 자동 수집하지 않습니다.

## 지원 범위

정규 이표, 고정금리, 만기 일시 원금 상환, 연 1/2/4/12회 지급, 최대 100년, 음수 YTM, 쿠폰 0인 무이표채, 선택적 월말 규칙을 지원합니다.

불규칙 첫 이표, 발행 전 선매출, 영업일·휴일 지급일 조정, 이자락 기간, 세금·수수료, 지급액·단가 절사, 물가연동, 변동금리, 콜·풋, 중도상환은 미지원입니다. 입력 오류는 조용히 보정하지 않고 알립니다. 선매출은 한국은행 공고에서도 별도 산식을 사용하므로 발행 전 결제는 명시적으로 거부합니다.

국내 시장의 단가 절사나 세금 관행 전체를 재현한 거래용 평가 시스템이 아니라, 현금흐름과 민감도를 확인하는 학습용 계산기입니다.

## 파일 구성

```text
bondcalc/core.py          현금흐름·가격·YTM·듀레이션·컨벡시티·KRD
bondcalc/gui.py           데스크톱 입력 화면과 표·그래프
bondcalc/report.py        입력 읽기·결과 저장·시장자료 비교
bondcalc/__main__.py      터미널 실행
data/ktb_example.json     실제 발행조건 기반 예제와 출처·가정
data/market_observation.template.json  시장자료 입력 양식
tests/                   계산·보고서·화면 검증
reports/ktb-example.json  재현 가능한 예제 결과
data/disclosed_trades.json  공시 실거래 원자료 3건과 한계
bondcalc/disclosures.py   공시금액 환산단가 비교
reports/disclosure-comparison.json  공시금액과 모델 가격 비교 결과
reports/검증결과.md        계산 검증 결과와 시장자료 확보 상태
학습실험.md               직접 실행하며 남길 실험 기록 양식
```
