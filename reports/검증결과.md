# 검증 결과 — 2026-09-09

계산 엔진과 데스크톱 화면의 동작 검증, 공시 실거래 금액 3건의 대략적 비교를 완료했습니다. 결제일·가격종류가 확인된 정밀 관측시장가격과의 일치 검증은 미완료입니다.

## 실행 환경과 재현

- Python 3.14.3 / Tk 8.6 / Windows
- 추가 패키지 없음
- `python -m unittest discover -s tests -v`: **26개 테스트 통과**
- `python -m bondcalc --output reports/ktb-example.json`: 정상 종료, 결과 JSON 생성
- 화면은 숨김 창으로 초기 계산, 값 변경, 결과 무효화, 역산, 입력 오류 처리를 검사했습니다. 실제 창의 시각적 배치는 별도 육안 검증하지 않았습니다.

## 계산 정확성

| 검증 | 비교 기준 | 결과 |
|---|---|---|
| 2년 연 이표채 가격 | 독립 폐쇄형 식 `5/1.1 + 105/1.1^2` | 일치 |
| 국고채 단리 가격 | 날짜와 6개 현금흐름을 별도 지정한 50자리 Decimal 참조식 | 1e-8원 이내 |
| YTM 역산 | 난수 고정, 40개 결제일·금리 사례 × 2개 할인 방식 × 2개 가격 종류 | 허용오차 내 |

## 국고채 조건 예제

국고02250-2806, 발행 2025-06-10, 만기 2028-06-10, 반기 쿠폰 2.25%, 액면 10,000원. 2025-10-13 한국은행 공표 낙찰금리 2.565%를 사용했습니다. 결제일 2025-10-14는 분석 가정입니다.

- Dirty 가격: 9,996.757740원
- Clean 가격: 9,919.298723원
- 경과이자: 77.459016원
- Macaulay: 2.573077년
- Modified: 2.541848
- 컨벡시티: 7.805170
- DV01: 2.541023원

| 금리 충격 | 실제 가격 변화(원) | 듀레이션 근사−실제(원) | 컨벡시티 포함 근사−실제(원) |
|---|---:|---:|---:|
| −100bp | +258.050440 | −3.948091 | −0.046771 |
| +100bp | −250.246865 | −3.855485 | +0.045835 |

큰 금리 충격에서 컨벡시티를 포함하면 이 예제의 근사 오차가 줄었습니다. 가격 반응은 금리 상승·하락에 대해 대칭이 아닙니다.

학습용 평탄 **복리** 제로커브의 KRD 합−평행이동 민감도 차이는 약 −3.17e-8입니다. 이 커브는 관측 시장 제로커브가 아닙니다.

## 시장가격 검증의 남은 조건

2026-09-09 한국거래소 Data Marketplace의 `채권 → 종목시세 → 전종목 시세` 조회 시 로그인 또는 회원가입이 필요하다는 안내를 확인했습니다. 결제일·가격종류까지 확인된 독립적인 시장가격이 없으므로 기본 예제는 `market_observation: null`, 상태는 `pending`입니다. 아래 공시 비교는 별도 제한적 증거입니다.

## 공시 실거래 자료와의 대략적 가격 비교

[삼성증권 2025-10-21 공시](https://kind.krx.co.kr/external/2025/10/21/000351/20251021000932/80754.htm)에서 국고02250-2806(25-4)의 거래금액·총권면금액·유통수익률 3건을 확보했습니다. 계산단가는 `거래금액/총권면금액*10,000`이며 단위는 원입니다.

| 거래일 | 거래금액/권면 (억원) | 수익률 % | 공시금액 환산단가 | 당일 결제 가정 Dirty | 다음날 결제 가정 Dirty |
|---|---:|---:|---:|---:|---:|
| 2025-08-25 | 999.8 / 1,000 | 2.433 | 9,998.000000 | 9,997.264153 | 9,997.924075 |
| 2025-09-22 | 20.0 / 20 | 2.463 | 10,000.000000 | 10,007.956737 | 10,008.626707 |
| 2025-09-22 | 80.1 / 80 | 2.463 | 10,012.500000 | 10,007.956737 | 10,008.626707 |

다음날 결제 가정에서 차이는 각각 약 −0.076원, +8.627원, −3.873원입니다. 공시금액이 0.1억원 단위 최근접 반올림이고 권면금액이 정확하다고 가정하면 단가의 표시 오차 범위는 각각 ±0.5원, ±25원, ±6.25원입니다. 다음날 결제 계산값은 이 가정 범위 안에 있지만, 반올림 규칙·Dirty 여부·실제 결제일이 확인되지 않았으므로 정확한 시장 일치나 합격을 주장하지 않습니다. 결제일은 결과에 맞춰 확정하지 않고 당일/다음날 양쪽을 남겼습니다.

`python -m bondcalc.disclosures`로 같은 비교를 재현합니다. 원자료는 `data/disclosed_trades.json`, 전체 결과는 `reports/disclosure-comparison.json`에 있습니다. 기본 예제의 정밀 시장 검증 대기 상태는 유지합니다.

다음 자료가 필요합니다: 같은 종목의 가격과 독립 YTM, 같은 관측시각, 실제 결제일, 액면기준, 가격의 Clean/Dirty 구분, 호가/종가 구분, 원본 출처. 이 자료를 입력하면 비교값을 만들 수 있습니다. 낙찰금리로 계산한 가격을 다시 비교 대상으로 쓰면 독립 검증이 되지 않습니다.

발행조건·계산식·데이터 접근 경로의 출처는 프로젝트 README와 예제 입력 JSON에 기록했습니다.
